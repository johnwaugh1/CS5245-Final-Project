# CS5245-Final-Project

This repository contains the full workflow for predicting wildfire burn severity using multi-fire remote sensing data, environmental variables, and classical machine learning models such as Random Forest, XGBoost, LightGBM, Logistic Regression, and CatBoost.

Environment Setup
    - Install dependencies using requirements.txt

Data is not included in repo or is not updated because the datasets are too large.

Run notebooks one by one in order to extract data, validate that data was extracted, preprocess data, train models, and visualize results.
